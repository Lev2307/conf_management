# Визуализатор графа зависимостей NuGet

Учебный проект по дисциплине «Конфигурационное управление»,
практическая работа № 2, вариант 1.

CLI-инструмент для построения графа зависимостей пакетов .NET (NuGet).
Готовые менеджеры пакетов и библиотеки для получения зависимостей
не используются — только стандартная библиотека Python.

## Этап 1. Минимальный прототип с конфигурацией

Приложение принимает параметры из командной строки, проверяет их
и выводит в формате `ключ = значение`. При ошибке выводится понятное
сообщение и программа завершается с ненулевым кодом.

### Параметры

| Параметр | Обязательный | По умолчанию | Описание |
|---|---|---|---|
| `--package` | да | — | имя анализируемого пакета NuGet |
| `--repo` | да | — | URL репозитория NuGet или, при `--test-mode`, путь к файлу тестового репозитория |
| `--test-mode` | нет | выключен | режим тестового репозитория (флаг без значения) |
| `--output` | нет | `graph.png` | имя PNG-файла с изображением графа |
| `--max-depth` | нет | `3` | максимальная глубина анализа зависимостей (от 1 до 50) |

### Проверки параметров

| Параметр | Ошибка |
|---|---|
| `--package` | не задан; пустой; содержит символы, кроме `A-Z a-z 0-9 . - _` |
| `--repo` | не задан; пустой; в обычном режиме — не URL `http(s)://` с адресом сервера; в тестовом режиме — файл не найден или это папка |
| `--output` | пустой; расширение не `.png`; папка для файла не существует; путь указывает на папку |
| `--max-depth` | не целое число; меньше 1 или больше 50 |

Коды завершения: `0` — успех, `1` — ошибка значения параметра,
`2` — ошибка разбора командной строки (сообщение argparse).

## Структура проекта

```
├── src/
│   ├── main.py      # точка входа: разбор аргументов, вывод параметров
│   └── config.py    # класс Config, ConfigError и проверки параметров
├── tests/           # тесты pytest
├── scripts/         # bat-скрипты и тестовые данные
├── pytest.ini
└── README.md
```

## Запуск

Требуется Python 3.10+, сторонние пакеты для работы не нужны.

```
py src\main.py --help
py src\main.py --package Newtonsoft.Json --repo https://api.nuget.org/v3/index.json
py src\main.py --package A --repo scripts\test_repo.txt --test-mode --max-depth 5
```

## Тесты

```
py -m pip install pytest flake8
py -m pytest
py -m flake8 --max-line-length 80 --max-complexity 10 src tests
```

## Демонстрационные скрипты

| Скрипт | Что показывает |
|---|---|
| `test_ok.bat` | правильные запуски: обычный режим, тестовый режим, значения по умолчанию |
| `test_errors.bat` | обработку ошибок для каждого параметра |

Запуск из PowerShell в корне проекта: `.\scripts\test_errors.bat`

## Пример работы

```
> py src\main.py --package Newtonsoft.Json --repo https://api.nuget.org/v3/index.json
package = Newtonsoft.Json
repo = https://api.nuget.org/v3/index.json
test_mode = False
output = graph.png
max_depth = 3

> py src\main.py --package A --repo api.nuget.org
Ошибка: --repo должен быть URL (http/https), получено: api.nuget.org

> py src\main.py --package A --repo https://api.nuget.org/v3/index.json --max-depth 0
Ошибка: max_depth должна быть от 1 до 50, получено: 0
```
