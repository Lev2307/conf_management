# Ассемблер и интерпретатор УВМ (вариант 1)

Учебная виртуальная машина со стеком и объединённой памятью
команд и данных. Размер команды — 5 байт: биты 0–2 — код
команды (поле A), остальные биты — операнд (поле B).

## Структура репозитория

    src/
        main.py        — точка входа (подкоманды assemble и run)
        assembler.py   — сборка программы (CSV -> двоичный файл)
        interpreter.py — исполнение программы (дамп памяти XML)
        reader.py      — разбор CSV-файла
        encoder.py     — промежуточное представление -> машинный код
        decoder.py     — машинный код -> промежуточное представление
        machine.py     — память, стек и цикл исполнения УВМ
        dump.py        — XML-дамп памяти
        instruction.py — промежуточное представление команды
        opcodes.py     — коды команд и формат команды
    programs/          — примеры программ на языке ассемблера
    tests/             — тесты

## Язык ассемблера

Программа — текстовый файл в формате CSV, по одной команде
в строке: `<мнемоника>,<операнд>`. Пустые строки и строки,
начинающиеся с `#`, игнорируются.

| Мнемоника | A | B | Описание |
|-----------|---|---|----------|
| const | 5 | константа | положить константу на стек |
| load | 0 | смещение | прочитать память `[стек + смещение]` на стек |
| store | 3 | смещение | записать вершину стека в память `[стек + смещение]` |
| bswap | 7 | смещение | записать `bswap(вершина стека)` в память `[стек + смещение]` |

## Запуск

Единая точка входа — `src/main.py` с подкомандами:

    python src/main.py assemble <исходник.csv> <результат.bin> [--test]
    python src/main.py run <программа.bin> <дамп.xml> <начало> <конец>

Флаг `--test` у `assemble` выводит промежуточное представление
и машинный код в байтовом формате, как в тестах спецификации УВМ.

### Примеры запуска

Проверка тестов из спецификации УВМ — ассемблирует
`programs/spec_tests.csv` в `spec_tests.bin`, а флаг `--test`
дополнительно печатает поля команд и байтовые последовательности,
которые должны совпасть с примерами из задания:

    python src/main.py assemble programs/spec_tests.csv spec_tests.bin --test

Сборка тестовой программы копирования массива
(`programs/copy_array.csv` -> `copy.bin`):

    python src/main.py assemble programs/copy_array.csv copy.bin

Исполнение программы с дампом памяти — выполняет `copy.bin`
и сохраняет ячейки памяти из диапазона [2000, 2016) в `dump.xml`:

    python src/main.py run copy.bin dump.xml 2000 2016

## Машинный код

Каждая команда кодируется 5-байтовым словом (little-endian):
младшие 3 бита — код команды A, остальные биты — операнд B.
Слово вычисляется как `A | (B << 3)`.

## Интерпретатор

Память команд и данных объединена (4096 байт), ячейки данных —
32-битные слова little-endian. Диапазон дампа [начало, конец) должен
быть кратен 4. После выполнения программы дамп сохраняется в XML.

Дисциплина стека: `store` снимает сначала значение, затем адрес,
поэтому в программе сначала кладётся адрес, потом значение.
