# Эмулятор оболочки ОС

Учебный проект по дисциплине «Конфигурационное управление», вариант 1.
Эмулятор командной строки UNIX-подобной ОС с графическим интерфейсом
на Python (tkinter).

## Возможности

### Этап 1. REPL

- Окно с полем вывода и строкой ввода, команда выполняется по Enter.
- В заголовке окна и в приглашении отображается имя VFS
  (по умолчанию `vfs`).
- Простой парсер: ввод делится на команду и аргументы по пробелам.
- Команды:

| Команда | Описание |
|---|---|
| `ls [аргументы]` | заглушка: выводит имя команды и аргументы |
| `cd [путь]` | заглушка: выводит имя команды и аргумент; больше одного аргумента — ошибка |
| `exit` | закрывает эмулятор |

- Ошибки: неизвестная команда (`foo: command not found`),
  лишние аргументы (`cd: too many arguments`).

### Этап 2. Конфигурация

Параметры командной строки:

| Параметр | Описание |
|---|---|
| `--vfs <путь>` | путь к физическому расположению VFS |
| `--script <путь>` | путь к стартовому скрипту |

- При запуске выводятся все параметры (`[DEBUG] vfs = ...`,
  `[DEBUG] script = ...`), включая незаданные (`None`).
- Если файл VFS или скрипта не найден, выводится сообщение
  об ошибке, эмулятор продолжает работу.
- Стартовый скрипт — текстовый файл (UTF-8) с командами эмулятора,
  по одной на строку. При выполнении на экране отображаются и ввод,
  и вывод, как в диалоге с пользователем.
- Скрипт **останавливается на первой ошибке** с сообщением
  `Скрипт остановлен на строке N`. После скрипта эмулятор остаётся
  в интерактивном режиме.

## Структура проекта

```
shell-emulator/
├── src/
│   ├── main.py          # точка входа, разбор аргументов
│   ├── gui.py           # окно эмулятора, выполнение скрипта
│   ├── shell_parser.py  # парсер строки
│   └── commands.py      # команды эмулятора
├── tests/               # тесты pytest
├── scripts/
│   ├── emulator/        # стартовые скрипты эмулятора и тестовая VFS
│   └── os/              # bat-скрипты для проверки параметров
├── pytest.ini
└── README.md
```

## Запуск

Требуется Python 3.10+ (tkinter входит в стандартную поставку).

```
py src\main.py
py src\main.py --vfs scripts\emulator\vfs.csv
py src\main.py --script scripts\emulator\ok.txt
py src\main.py --vfs scripts\emulator\vfs.csv --script scripts\emulator\ok.txt
```

## Тесты

```
py -m pip install pytest flake8
py -m pytest
py -m flake8 --max-line-length 80 --max-complexity 10 src tests
```

## Тестовые скрипты

Стартовые скрипты эмулятора (`scripts/emulator`):

| Файл | Что проверяет |
|---|---|
| `ok.txt` | команды без ошибок |
| `error.txt` | остановка на первой ошибке |
| `exit.txt` | выход из эмулятора командой из скрипта |

Скрипты ОС (`scripts/os`), запуск из PowerShell:
`.\scripts\os\test_script.bat`

| Файл | Параметры |
|---|---|
| `test_no_args.bat` | без параметров |
| `test_vfs.bat` | только `--vfs` |
| `test_script.bat` | только `--script` |
| `test_all.bat` | `--vfs` и `--script` |
| `test_missing.bat` | несуществующие пути |
| `test_error.bat` | скрипт с ошибкой |

## Пример работы

Запуск `py src\main.py --vfs scripts\emulator\vfs.csv --script scripts\emulator\error.txt`:

```
[DEBUG] vfs = scripts\emulator\vfs.csv
[DEBUG] script = scripts\emulator\error.txt
VFS name: vfs.csv
Script name: error.txt
vfs.csv$ ls
ls: args=[]
vfs.csv$ foo
foo: command not found
Скрипт остановлен на строке 2
```
